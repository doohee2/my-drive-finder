구글 드라이브의 엑셀(.xls, .xlsx) 및 CSV 데이터를 브라우저 로컬 DB에 캐싱하고 고속으로 검색해 주는 모바일 PWA 최적화 반응형 웹앱 '마이 드라이브 파인더(My Drive Finder)'의 UI와 프론트엔드 컴포넌트를 디자인해 줘. 
React와 Tailwind CSS 기반으로 작성해 주되, 복잡함을 배제하고 직관적인 탐색과 모바일 사용성을 극대화할 수 있도록 아래의 레이아웃과 상태 규칙을 엄격히 적용해 줘.

### 1. 전체 화면 레이아웃 (Global Layout)
- **상단 헤더 (App Header):** 좌측에는 앱 타이틀('My Drive Finder')과 PWA 홈 화면 앱 아이콘 뱃지를 심플하게 배치해 줘. 우측에는 구글 로그인 프로필 이미지와 함께 **[로컬 캐시 동기화 상태 배지]**(예: "🟢 동기화됨 (10분 전)" 또는 스피너 애니메이션)를 배치하여 현재 데이터의 최신 상태를 직관적으로 알 수 있게 해줘.
- **메인 컨테이너:** 데스크톱에서는 중앙 정렬된 여유로운 너비(max-w-5xl)로, 모바일에서는 좌우 여백 없이 화면을 꽉 채우는 레이아웃으로 구성해 줘.

### 2. 폴더 설정 및 동기화 제어 영역 (Folder Picker Section)
- 화면 상단 또는 아코디언(접기/펼치기) 메뉴 형태로 **[타겟 폴더 설정 카드]**를 구성해 줘.
- 현재 연동된 구글 드라이브 폴더 경로(예: `My Drive > 2026_재무기록`)를 텍스트로 표시하고, 옆에 [폴더 변경] 버튼을 둬서 구글 드라이브 파일 피커(Picker)가 모달로 뜰 수 있는 진입점을 만들어 줘.
- 허용되는 파일 유형(`.xlsx`, `.csv`)을 나타내는 작고 세련된 확장자 태그 칩(Chip)들을 폴더명 옆에 나란히 보여줘.

### 3. 핵심 기능: 복합 조건 검색 바 (Search Interface)
사용자가 데이터를 채굴(Mining)하는 핵심 영역이므로 가장 눈에 띄고 쓰기 편해야 해.
- **메인 검색 창 (Include):** 돋보기 아이콘과 함께 "검색어 입력 (예: 홍길동, 인터스텔라)..." 플레이스홀더를 가진 큼직한 Input 텍스트 필드를 중앙에 배치해 줘.
- **고급 필터 옵션 (Exclude - 토글형):** 메인 검색 바 우측이나 하단에 **[+ 제외 단어 추가]** 토글 버튼을 둬서, 클릭 시 "검색에서 제외할 단어 입력..." Input 필드가 부드럽게 펼쳐지는 UI를 구현해 줘. (초기 화면을 깔끔하게 유지하기 위함)
- 우측 끝에는 강조된 브랜드 컬러의 **[검색하기]** 액션 버튼을 배치해 줘.

### 4. 검색 결과 시각화 및 반응형 레이아웃 (Results Visualization - 핵심 ⭐️)
검색이 완료되면 매칭된 데이터들을 **'파일 이름' 기준으로 그룹화(Sectioning)**하여 보여줘야 해. 각 파일 섹션마다 엑셀/CSV 아이콘과 함께 파일명(예: `경조사비_내역.xlsx`), 그리고 매칭된 건수(예: "총 4건 발견")를 헤더로 표시해 줘.

디바이스 크기에 따라 아래 두 가지 모드로 화면 전환이 부드럽게 일어나도록 반응형 클래스(sm:, md: 등)를 적용해 줘.
- **[데스크톱 뷰 (PC) - 테이블 모드]:** 넓은 화면에서는 엑셀처럼 직관적인 표(`<table>`) 형태로 렌더링해 줘. 첫 줄은 컬럼 명(`<thead>`)으로 강조하고, 홀/짝수 행의 배경색을 미세하게 다르게(Zebra striping) 처리해 가독성을 높여줘.
- **[모바일 뷰 (Mobile PWA) - 카드 모드]:** 화면 너비가 좁은 모바일(아이폰 등)에서는 표(Table)가 화면 밖으로 넘치지 않도록, 각 레코드(행)를 독립된 **'명함 형태의 카드(Card)'** 레이아웃으로 변환해 줘. Card 내부에서는 `컬럼명: 값` 형태로 가로 배치하여 스와이프 없이 한눈에 읽을 수 있게 해줘.
- **[빈 상태 (Empty State)]:** 초기 실행 시나 검색 결과가 없을 때는 중앙에 일러스트나 아이콘과 함께 "검색어를 입력하여 로컬에 캐시된 드라이브 파일을 빠르게 탐색해 보세요"라는 안내 문구를 띄워줘.

### 5. 스타일 가이드 (Style & Vibe)
- **Tailwind CSS**를 적극 활용해 줘.
- 복잡한 원색보다는 차분하고 전문적인 느낌을 주는 '슬레이트 그레이(Slate/Gray)' 바탕에, 구글 드라이브를 연상시키는 '소프트 블루' 또는 '에메랄드 그린'을 포인트 컬러로 사용해 줘.
- 테두리 선은 최소화하고 부드러운 그림자(`shadow-sm`, `shadow-md`)와 여백(Padding)으로 요소들을 분리해 줘.
- 다크 모드 전환을 완벽히 지원하도록 모든 컴포넌트에 `dark:` 분기 처리를 꼼꼼히 세팅해 줘.
